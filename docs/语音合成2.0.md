# 语音合成2.0

官方文档：<https://www.volcengine.com/docs/6561/2532486>

本文整理语音合成 2.0 WebSocket 双向流式 TTS 接口，并标注当前 SDK 已实现的能力边界。

## SDK 实现状态

当前仓库已经实现该接口的核心双向流式流程：

- WebSocket 路径：`wss://openspeech.bytedance.com/api/v3/tts/bidirection`
- 代码入口：`TTSServiceV2.OpenStreamSession`
- 示例目录：`examples/tts_v2/websocket`

已暴露能力：

- `StartConnection` / `ConnectionStarted`
- `StartSession` / `SessionStarted`
- `TaskRequest` 文本输入
- 音频流式输出
- `FinishSession`
- `FinishConnection`
- `CancelSession`
- 多文本分片
- 多 session 顺序复用连接
- `speaker`
- `audio_params.format`
- `audio_params.sample_rate`

尚未暴露为高层 API：

- `model`
- `context_texts`
- `use_tag_parser`
- `enable_subtitle` / `TTSSubtitle`
- `usage.text_words`
- AIGC 水印、缓存、后处理、显式语种、显式方言

## 请求

请求地址：

```text
wss://openspeech.bytedance.com/api/v3/tts/bidirection
```

## 鉴权

新版控制台请求头：

| Header | 必选 | 说明 |
| --- | --- | --- |
| `X-Api-Key` | 是 | API Key，可从新版控制台 API Key 管理获取 |
| `X-Api-Resource-Id` | 是 | 请求的模型版本 |
| `X-Api-Connect-Id` | 否 | 当前 WebSocket 连接追踪 ID |
| `X-Control-Require-Usage-Tokens-Return` | 否 | 设置为 `*` 时返回计费字符数 |

旧版控制台鉴权也可用于该接口。

资源 ID：

| Resource ID | 说明 |
| --- | --- |
| `seed-tts-2.0` | 豆包语音合成大模型 2.0 |
| `seed-icl-2.0` | 豆包声音复刻大模型 2.0 |

## 事件流程

| 阶段 | 请求事件 | 响应事件 | 说明 |
| --- | --- | --- | --- |
| 建立连接 | `StartConnection` | `ConnectionStarted` | 初始化 WebSocket 连接 |
| 创建会话 | `StartSession` | `SessionStarted` | 创建合成会话 |
| 发送文本 | `TaskRequest` | `TTSSentenceStart` / `TTSResponse` / `TTSSentenceEnd` | 文本输入、音频输出 |
| 取消会话 | `CancelSession` | `SessionCanceled` | 取消当前会话 |
| 结束会话 | `FinishSession` | `SessionFinished` | 结束当前合成会话 |
| 结束连接 | `FinishConnection` | `ConnectionFinished` | 关闭连接 |

失败事件：

- `ConnectionFailed`
- `SessionFailed`

响应消息类型：

- `FullServerResponse`
- `AudioOnlyServer`

## StartSession 参数

`req_params` 字段：

| 字段 | 类型 | 必选 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 否 | 具体模型版本，复刻音色场景可用 |
| `speaker` | string | 是 | 音色 ID |
| `audio_params` | object | 是 | 输出音频参数 |
| `additions` | string | 否 | 附加文本处理参数 |
| `context_texts` | array | 否 | 语音指令 |
| `use_tag_parser` | bool | 否 | 是否开启语音标签 cot 解析 |
| `section_id` | string | 否 | 多轮会话上下文 ID |

`model` 可选值：

| model | 说明 |
| --- | --- |
| `seed-tts-2.0-standard` | 标准版模型，时延更低；不支持 `context_texts` 和 `use_tag_parser` |
| `seed-tts-2.0-expressive` | 高表现力版本；支持 `context_texts` 和 `use_tag_parser` |

默认值：`seed-tts-2.0-standard`。

## audio_params

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `format` | string | 支持 `mp3`、`pcm`、`ogg_opus`、`wav`，默认 `mp3` |
| `sample_rate` | int | 支持 `8000`、`16000`、`22050`、`24000`、`32000`、`44100`、`48000` |
| `bit_rate` | int | 比特率，仅对 `mp3` 生效 |
| `speech_rate` | int | 语速，范围 `[-50, 100]` |
| `loudness_rate` | int | 音量，范围 `[-50, 100]` |
| `enable_subtitle` | bool | 是否开启字幕服务，返回字级别时间戳 |

流式场景推荐使用 `pcm`，不建议使用 `wav`。

## additions

## 语音指令和标签

`context_texts` 是语音指令，不参与计费：

```json
{
  "context_texts": [
    "你可以用特别特别痛心的语气说话吗?"
  ]
}
```

`use_tag_parser` 用于开启语音标签 cot 解析能力，仅复刻音色支持：

```text
<cot text=急促难耐>工作占据了生活的绝大部分</cot>，只有去做自己认为伟大的工作，才能获得满足感。
```

使用复刻音色并开启 `context_texts` 或 `use_tag_parser` 时，需要将 `model` 设置为 `seed-tts-2.0-expressive`。

## TaskRequest

`TaskRequest` 发送待合成文本：

```json
{
  "EventType": "TaskRequest",
  "session_id": "<session_id>",
  "text": "待合成文本"
}
```

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `EventType` | string | 响应事件类型 |
| `MsgType` | string | 响应消息类型 |
| `session_id` | string | 合成会话 ID |
| `connect_id` | string | WebSocket 连接 ID |
| `payload` | object | 当前事件携带的响应内容 |

`payload` 可包含：

- `text`
- `phonemes`
- `words`
- `usage`

`usage.text_words` 表示本次请求计费文本字数，含标点。

## SDK 使用

示例路径：

```text
examples/tts_v2/websocket
```

API Key 模式：

```bash
DOUBAO_API_KEY=<your_api_key> \
go run ./examples/tts_v2/websocket \
  -text "hello from tts v2 websocket" \
  -speaker zh_female_xiaohe_uranus_bigtts \
  -resource-id seed-tts-2.0 \
  -format mp3 \
  -sample-rate 24000 \
  -output ./tts_v2_ws_output.mp3
```

旧鉴权模式：

```bash
DOUBAO_APP_ID=<your_app_id> \
DOUBAO_ACCESS_KEY=<your_access_key> \
go run ./examples/tts_v2/websocket \
  -text "hello from tts v2 websocket" \
  -speaker zh_female_xiaohe_uranus_bigtts \
  -resource-id seed-tts-2.0
```

高级示例：

```bash
DOUBAO_API_KEY=<your_api_key> \
go run ./examples/tts_v2/websocket \
  -segments "hello|second segment|third segment" \
  -sessions 2 \
  -reuse-connection \
  -speaker zh_female_vv_uranus_bigtts \
  -resource-id seed-tts-2.0 \
  -output ./tts_v2_ws_output.mp3
```

## 音色和资源匹配

| Resource ID | 音色后缀 | 示例 |
| --- | --- | --- |
| `seed-tts-2.0` | `*_uranus_bigtts` | `zh_female_xiaohe_uranus_bigtts` |
| `seed-tts-1.0` | `*_moon_bigtts` | `zh_female_shuangkuaisisi_moon_bigtts` |

如果资源和音色不匹配，服务端通常返回：

```text
55000000 resource ID is mismatched with speaker related resource
```

## 常见错误

- 缺少鉴权信息。
- 账号未开通对应资源。
- `X-Api-Resource-Id` 和 `speaker` 所属资源不匹配。
- API Key 未开通该服务。
- 使用复刻音色扩展能力时未设置正确的 `model`。
