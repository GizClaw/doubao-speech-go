# 音频生成1.0

官方文档：<https://www.volcengine.com/docs/6561/2550782>

本文整理音频生成 1.0 HTTP 非流式接口。

## SDK 实现状态

当前仓库尚未实现该 API。

该接口是独立的新 API，不同于已实现的 TTS 2.0 HTTP 流式接口和 TTS 2.0 WebSocket 双向流式接口。

## 用途

基于 HTTP 协议的非流式音频生成接口。支持上传多个参考音频或图片生成音频，也支持通过自然语言描述生成音效、音色等，适用于有声书、配音、游戏等场景。

当前最长支持 120 秒音频输出。

## 请求

请求地址：

```text
https://openspeech.bytedance.com/api/v3/tts/create
```

## 鉴权

新版控制台请求头：

| Header | 必选 | 说明 |
| --- | --- | --- |
| `X-Api-Key` | 是 | API Key，可从新版控制台 API Key 管理获取 |
| `X-Api-Request-Id` | 否 | 客户端请求追踪 ID，建议使用内部 TraceID 或 UUID |

旧版控制台使用双头鉴权：

- `X-Api-App-Id`
- `X-Api-Access-Key`

## 请求体

| 字段 | 类型 | 必选 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | 模型版本标识，当前仅支持 `seed-audio-1.0` |
| `text_prompt` | string | 是 | 用于生成音频的 prompt 或待合成文本，最大 2048 字符 |
| `references` | array | 否 | 参考资源列表 |
| `audio_config` | object | 否 | 输出音频配置 |
| `watermark` | object | 否 | 水印配置 |

## 生成模式

| 模式 | references | text_prompt |
| --- | --- | --- |
| 纯文本生成 | 不传参考资源 | 按提示词生成音频 |
| 参考音频生成 | 传入音频参考 | 可通过 `@音频N` 引用对应参考音频 |
| 参考图片生成 | 传入图片参考 | 可只传入待合成文本 |

参考音频编号按上传顺序从 1 开始。

## references

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `speaker` | string | 音色 ID，可使用豆包语音合成模型 2.0 音色或声音复刻音色 |
| `audio_data` | string | 参考音频 base64 编码 |
| `audio_url` | string | 参考音频 URL |
| `image_data` | string | 参考图片 base64 编码 |
| `image_url` | string | 参考图片 URL |

音频参考规则：

- `speaker`、`audio_data`、`audio_url` 三选一。
- 最多支持三条参考音频。
- 每条参考音频最长 30 秒，大小不超过 10 MB。
- 参考音频格式支持 `wav`、`mp3`、`pcm`、`ogg_opus`。

图片参考规则：

- `image_data`、`image_url` 二选一。
- 仅支持一张参考图片，大小不超过 10 MB。
- 参考图片格式支持 `jpeg`、`png`、`webp`。
- 图片参考不能和音频参考混用。

## audio_config

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `format` | string | 输出格式，支持 `wav`、`mp3`、`pcm`、`ogg_opus`，默认 `wav` |
| `sample_rate` | int | 输出采样率，默认 `24000`，可选 `8000`、`16000`、`24000`、`32000`、`44100`、`48000` |
| `speech_rate` | int | 语速，范围 `[-50, 100]`，默认 `0` |
| `loudness_rate` | int | 音量，范围 `[-50, 100]`，默认 `0` |
| `pitch_rate` | int | 音调，范围 `[-12, 12]`，默认 `0` |

## watermark

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `aigc_watermark` | bool | 显式水印开关，开启后在合成结尾增加音频节奏标识，默认 `false` |
| `aigc_metadata` | object | 隐式水印，在合成音频 header 加入元数据 |

`aigc_metadata` 字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `enable` | bool | 是否启用隐式水印，默认 `false` |
| `content_producer` | string | 合成服务提供者名称或编码 |
| `produce_id` | string | 内容制作编号 |
| `content_propagator` | string | 内容传播服务提供者名称或编码 |
| `propagate_id` | string | 内容传播编号 |

## 请求示例

纯文本生成：

```json
{
  "model": "seed-audio-1.0",
  "text_prompt": "生成一段适合游戏开场的神秘环境音，持续约十秒。",
  "audio_config": {
    "format": "wav",
    "sample_rate": 24000
  }
}
```

参考音频生成：

```json
{
  "model": "seed-audio-1.0",
  "text_prompt": "参考 @音频1 的音色，生成一段温柔的旁白。",
  "references": [
    {
      "audio_url": "https://example.com/reference.wav"
    }
  ],
  "audio_config": {
    "format": "mp3",
    "sample_rate": 24000
  }
}
```

## 响应

响应头：

| Header | 说明 |
| --- | --- |
| `X-Tt-Logid` | 服务端返回的 logid，用于排查问题 |

响应体：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int | 状态码 |
| `message` | string | 状态详情 |
| `audio` | string | 合成音频数据，base64 编码 |
| `duration` | float | 处理后音频时长，单位秒 |
| `original_duration` | float | 模型输出原始音频时长，计费用时，上限 120 秒 |
| `url` | string | 带过期时间的音频地址，有效期 2 小时 |
