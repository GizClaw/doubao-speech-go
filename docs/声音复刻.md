# 声音复刻

官方文档：<https://www.volcengine.com/docs/6561/2534906>

本文整理火山引擎声音复刻接口文档。该官方页通过同一个训练接口上传语音样本并训练自定义音色，响应里的 `model_type = 5` 表示复刻 2.0 模型类型。

## 用途

上传语音样本，训练自定义语音音色，用于后续语音合成。

## 请求

请求地址：

```text
https://openspeech.bytedance.com/api/v3/tts/voice_clone
```

## 鉴权

新版控制台请求头：

| Header | 必选 | 说明 |
| --- | --- | --- |
| `Content-Type` | 是 | 固定为 `application/json` |
| `X-Api-Key` | 是 | 从新版控制台 API Key 管理获取 |
| `X-Api-Request-Id` | 是 | 客户端请求 ID，建议使用随机 UUID |

## 请求体

| 字段 | 类型 | 必选 | 说明 |
| --- | --- | --- | --- |
| `speaker_id` | string | 是 | 唯一音色代号 |
| `custom_speaker_id` | string | 否 | 自定义音色代号，仅支持后付费音色 |
| `audio` | object | 是 | 音频对象 |
| `audio.data` | string | 是 | 音频二进制内容的 base64 编码 |
| `audio.format` | string | 视格式而定 | 音频格式；`pcm`、`m4a` 必传 |
| `text` | string | 否 | 参考文本，用于校验音频和文本差异 |
| `language` | int | 否 | 语种枚举，默认中文 |
| `extra_params` | object | 否 | 额外训练参数 |
| `extra_params.demo_text` | string | 否 | 试听文本，长度 4 到 300 字 |
| `extra_params.enable_audio_denoise` | bool | 否 | 是否开启降噪，默认 `false` |
| `extra_params.disable_volume_normalization` | bool | 否 | 是否关闭音量归一化，默认 `false` |

## 自定义音色 ID

使用自定义音色时，`speaker_id` 必须传固定值 `custom_speaker_id`，实际自定义名称写在 `custom_speaker_id` 字段中：

```json
{
  "speaker_id": "custom_speaker_id",
  "custom_speaker_id": "custom_zh_xxx"
}
```

命名规则：

- 长度 8 到 256 个字符。
- 仅支持数字、大小写字母、中划线 `-`、下划线 `_`。
- 必须以英文字母开头。
- 首位和末位不可为 `-` 或 `_`。
- 同一 accountID 下不可重复。
- 不可与官方精品音色重名。

官方冲突和格式校验正则：

```go
`^((?i:S_|ICL_|MIX_|DiT_|BV)|[a-z]{2}_|(?i:(wvae|moon|mercury|venus|earth|mars|jupiter|saturn|uranus|neptune|pluto|umm)_)).*|.*_(?i:bigtts|bigtts_cc|tob|cs_tob|streaming)$|^[^a-zA-Z]|.*[-_]$|^.{0,7}$|^.{257,}$|.*[^a-zA-Z0-9_-].*`
```

注意：首次调用合成接口即视为音色转正，并会收取音色槽位费。

## 音频要求

支持格式：

- `wav`
- `mp3`
- `ogg`
- `m4a`
- `aac`
- `pcm`

限制：

- 文件最大 10 MB。
- `pcm` 仅支持 24 kHz、单声道。
- `pcm`、`m4a` 必须显式传入 `audio.format`。
- `mp3`、`ogg`、`aac` 等格式可以不指定 `audio.format`。

## 语种

通用声音复刻支持：

| 值 | 语种 |
| --- | --- |
| `0` | 中文，默认 |
| `1` | 英文 |
| `2` | 日语 |
| `3` | 西班牙语 |
| `4` | 印尼语 |
| `5` | 葡萄牙语 |
| `8` | 韩语 |

豆包端到端实时语音模型支持中文和英文。

## 响应

响应头：

| Header | 说明 |
| --- | --- |
| `X-Tt-Logid` | 服务端返回的 logid，用于排查问题 |

响应体字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int | 请求状态码 |
| `message` | string | 请求状态信息或失败说明 |
| `available_training_times` | int | 当前 `speaker_id` 剩余训练次数 |
| `create_time` | int | 创建时间 |
| `language` | int | 语种枚举 |
| `speaker_id` | string | 唯一音色代号 |
| `status` | int | 训练状态 |
| `speaker_status` | object list | 音色状态列表 |
| `model_type` | int | 复刻 2.0 为 `5` |
| `demo_audio` | string | 试听音频 URL；成功时返回，一小时有效 |

## 状态枚举

| 值 | 状态 |
| --- | --- |
| `0` | `NotFound` |
| `1` | `Training` |
| `2` | `Success` |
| `3` | `Failed` |
| `4` | `Active` |

当状态为 `2` 或 `4` 时，可以调用 TTS 语音合成接口。

## 失败场景

- 如果传入 `text`，服务会对比音频与参考文本差异；差异过大时会失败并返回 `45001109 WERError`。
- 如果指定 `language`，`demo_text` 必须使用对应语种文本，否则可能合成失败。
- `demo_text` 越长，注册耗时越长，建议合理控制长度。
