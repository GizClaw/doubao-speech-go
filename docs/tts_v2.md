# TTS 2.0

Official documentation: <https://www.volcengine.com/docs/6561/2532486>

This page maps the VolcEngine TTS 2.0 bidirectional WebSocket API to the
current SDK surface. The API supports streaming text input, streaming audio
output, low latency, multiple languages, and dialect-oriented synthesis.

## Endpoint

```text
wss://openspeech.bytedance.com/api/v3/tts/bidirection
```

## SDK Coverage

The core bidirectional WebSocket flow is implemented by
`TTSV2.OpenStreamSession`.

Supported operations:

- API-key authentication headers
- `StartConnection`
- `StartSession`
- text `TaskRequest`
- streamed audio frames
- `CancelSession`
- `FinishSession`
- `FinishConnection`
- sequential session reuse on one WebSocket connection

Current `TTSV2WSConfig` typed fields:

| SDK field | Upstream path | Notes |
| --- | --- | --- |
| `Speaker` | `req_params.speaker` | Required voice ID. |
| `Format` | `req_params.audio_params.format` | Output audio format. |
| `SampleRate` | `req_params.audio_params.sample_rate` | Output audio sample rate. |
| `ResourceID` | `X-Api-Resource-Id` | Defaults to `seed-tts-2.0` through client resource resolution. |

The upstream fields below are documented for completeness. Fields that are not
listed in `TTSV2WSConfig` are not yet public SDK API; add typed structs and
tests before exposing them.

## Request Headers

| Header | Required | Meaning |
| --- | --- | --- |
| `X-Api-Key` | yes | API key authentication value. |
| `X-Api-Resource-Id` | yes | Model/resource version. |
| `X-Api-Connect-Id` | no | Connection trace ID for troubleshooting. |
| `X-Control-Require-Usage-Tokens-Return` | no | If set to `*`, returns billable character count. |

Resource IDs:

| Resource ID | Meaning |
| --- | --- |
| `seed-tts-2.0` | Doubao TTS 2.0. Supports Doubao TTS 2.0 voices. |
| `seed-icl-2.0` | Doubao Voice Clone 2.0. Supports voices cloned through the voice-clone API. |

## Client Events

### StartConnection

| Field | Type | Required | Value |
| --- | --- | --- | --- |
| `EventType` | string | yes | `StartConnection` |

The SDK sends this as event ID `1` with namespace `BidirectionalTTS`.

### StartSession

| Field | Type | Required | SDK field | Notes |
| --- | --- | --- | --- | --- |
| `EventType` | string | yes | internal | `StartSession`. |
| `session_id` | string | yes | generated internally | Synthesis session ID generated by client. |
| `req_params` | object | yes | partly typed | Session synthesis parameters. |

`req_params` fields:

| Field | Type | Required | SDK field | Default | Notes |
| --- | --- | --- | --- | --- | --- |
| `model` | string | no | not typed | `seed-tts-2.0-standard` | Used when `speaker` is a clone voice. |
| `speaker` | string | yes | `Speaker` | empty | Voice ID from Console > Voice Library. |
| `audio_params` | object | yes | partly typed | empty | Output audio configuration. |
| `additions` | string | no | not typed | empty | JSON-string extension parameters. |

`model` values:

| Value | Notes |
| --- | --- |
| `seed-tts-2.0-standard` | Standard model, lower latency. Does not support `context_texts` or `use_tag_parser`; default. |
| `seed-tts-2.0-expressive` | More expressive, less stable. Supports `context_texts` and `use_tag_parser`. |

### Audio Parameters

| Field | Type | Required | SDK field | Default | Notes |
| --- | --- | --- | --- | --- | --- |
| `format` | string | no | `Format` | `mp3` | `mp3`, `pcm`, `ogg_opus`, or `wav`. Streaming scenarios should prefer `pcm`; `wav` is not recommended. |
| `sample_rate` | int | no | `SampleRate` | service default | `8000`, `16000`, `22050`, `24000`, `32000`, `44100`, or `48000`. |
| `bit_rate` | int | no | not typed | range `64000` to `160000` | Audio bitrate in bps. Only applies to `mp3`. |
| `speech_rate` | int | no | not typed | `0` | Range `[-50,100]`; `100` is 2x, `-50` is 0.5x. |
| `loudness_rate` | int | no | not typed | `0` | Range `[-50,100]`; `100` is 2x volume, `-50` is 0.5x. |
| `enable_subtitle` | bool | no | not typed | `false` | Enables word-level timestamps. Only TTS 2.0 supports this; currently only Chinese and English. |

### Additions

`additions` is a JSON string in the upstream protocol.

| Field | Type | Default | Notes |
| --- | --- | --- | --- |
| `max_length_to_filter_parenthesis` | int | service default | `0` means do not filter parenthesized text; `100` means filter it. |
| `disable_markdown_filter` | bool | `false` | `true` parses and removes Markdown syntax, for example `**hello**` is read as `hello`; `false` keeps raw characters. |
| `disable_emoji_filter` | bool | `false` | Controls emoji parsing/filtering. |
| `enable_latex_tn` | bool | `false` | Enables LaTeX text reading. |
| `latex_parser` | string | empty | `v2` enables stronger LaTeX reading. It increases latency and requires `disable_markdown_filter=true`. |
| `explicit_language` | string | empty | Explicit reading language. When set, input text must contain that language or the request may fail/no-return. |
| `explicit_dialect` | string | empty | Explicit dialect. The selected `speaker` must support the dialect. |
| `aigc_watermark` | bool | `false` | Adds rhythm marker at the end of synthesized audio. |
| `aigc_metadata` | object | empty | Adds hidden metadata watermark to `mp3`, `wav`, or `ogg_opus`. |
| `cache_config` | object | empty | Cache configuration. |
| `post_process` | object | empty | Post-processing configuration. |
| `context_texts` | array | empty | Voice instructions. |
| `use_tag_parser` | bool | `false` | Enables voice-label COT parsing. |
| `section_id` | string | empty | Multi-turn session ID for serial synthesis in the same context. |

`explicit_language` values:

| Value | Meaning |
| --- | --- |
| `zh-cn` | Chinese-oriented; supports Chinese-English mixed reading. |
| `en` | English only. |
| `ja` | Japanese only. |
| `es-mx` | Mexican Spanish only. |
| `id` | Indonesian only. |
| `pt-br` | Brazilian Portuguese only. |
| `ko` | Korean only. |

`aigc_metadata` fields:

| Field | Type | Default | Notes |
| --- | --- | --- | --- |
| `enable` | bool | `false` | Enables hidden metadata watermark. |
| `content_producer` | string | empty | Synthesis service provider name or code. |
| `produce_id` | string | empty | Content production ID. |
| `content_propagator` | string | empty | Propagation service provider name or code. |
| `propagate_id` | string | empty | Propagation ID. |

`cache_config` fields:

| Field | Type | Notes |
| --- | --- | --- |
| `text_type` | int | Use with `use_cache`; pass `0` when enabling cache. |
| `use_cache` | bool | Use with `text_type`; pass `true` to enable cache. |

`post_process` fields:

| Field | Type | Notes |
| --- | --- | --- |
| `pitch` | int | Pitch range `[-12,12]`. |

`context_texts` notes:

- TTS 2.0 voices can use voice instructions directly.
- Clone voices require `model=seed-tts-2.0-expressive`.
- `context_texts` is not billed.

Example:

```json
{
  "context_texts": ["Can you speak with a very painful tone?"]
}
```

`use_tag_parser` notes:

- Only clone voices support COT parsing.
- Requires `speaker` to be a clone voice.
- Requires `model=seed-tts-2.0-expressive`.
- The `text` length is best kept under 64 characters including tags.

Example:

```text
<cot text=urgent>Work takes most of life</cot>, and only great work brings satisfaction.
<cot text=slow>Never stop looking, no matter how hard life gets.</cot>
```

`section_id` notes:

- Associates multiple serial TTS requests in the same context.
- The service saves conversation history after one synthesis and reads it for
  later requests using the same `section_id`.
- Use one UUID for multiple TTS requests in the same phone call or logical
  session.
- Applies to Doubao TTS 2.0 voices and Doubao Voice Clone 2.0 voices.
- The service has history turn-count and timeout limits.

Example:

```text
section_id="bf5b5771-31cd-4f7a-b30c-f4ddcbf2f9da"
```

## Server Events

| EventType | Meaning | SDK behavior |
| --- | --- | --- |
| `ConnectionStarted` | Connection created successfully. | Used during `OpenStreamSession`. |
| `ConnectionFailed` | Connection failed. | Returned as error. |
| `ConnectionFinished` | Connection ended. | Ignored by SDK receive loop. |
| `SessionStarted` | Session started. | Used during `OpenStreamSession` / `StartNextSession`. |
| `SessionFinished` | Session ended. | Returned as final chunk with `IsFinal=true`. |
| `SessionCanceled` | Session canceled. | Returned as final chunk with `IsFinal=true`. |
| `SessionFailed` | Session failed. | Returned as error. |
| `TTSSentenceStart` | TTS synthesis sentence starts. | Ignored by SDK receive loop. |
| `TTSResponse` | TTS audio data. | Decoded into `TTSV2WSChunk.Audio`. |
| `TTSSentenceEnd` | TTS synthesis sentence ends. | Ignored by SDK receive loop. |
| `TTSSubtitle` | TTS subtitle / timestamp payload. | Not currently parsed as a typed SDK event. |

Response metadata fields:

| Field | Type | Notes |
| --- | --- | --- |
| `MsgType` | string | `FullServerResponse` or `AudioOnlyServer`. |
| `session_id` | string | Synthesis session ID. |
| `connect_id` | string | WebSocket connection ID. |
| `payload` | object | Event payload. |

Subtitle/timestamp payload fields:

| Field | Type | Notes |
| --- | --- | --- |
| `phonemes` | object | Phoneme-related timestamps. |
| `text` | string | Synthesized text. |
| `words` | object/array | Word-level timestamps. |
| `words[].confidence` | float | Timestamp confidence, range 0 to 1. |
| `words[].startTime` | float | Start time in seconds. |
| `words[].endTime` | float | End time in seconds. |
| `words[].word` | string | Word/character. |

Usage payload:

| Field | Type | Notes |
| --- | --- | --- |
| `usage.text_words` | int | Billable text character count, including punctuation. Returned when usage return is requested. |

## Audio Output

The upstream API supports:

- `mp3`
- `pcm`
- `ogg_opus`
- `wav`

For streaming use cases, prefer `pcm` or `ogg_opus`. Avoid `wav` in streaming
flows because repeated WAV headers can appear across returned chunks.
