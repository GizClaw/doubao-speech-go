# 同声传译

官方文档：<https://www.volcengine.com/docs/6561/1756902>

本文整理火山引擎同传大模型 AST WebSocket API。该服务支持语音到语音（S2S）和语音到文本（S2T），可在 S2S 场景中复刻输入说话人的音色。

当前 SDK 通过 `Client.ASTTranslate` / `Client.AST` 提供同传接口封装，示例目录：

```text
examples/ast_v2_translate
```

## 接口地址

```text
wss://openspeech.bytedance.com/api/v4/ast/v2/translate
```

固定资源 ID：

```text
volc.service_type.10053
```

## 支持模式和语种

| 输入/输出模式 | 源语种/目标语种设置 | 支持语种 | 备注 |
| --- | --- | --- | --- |
| S2S 语音到语音 | 需指定源语种、目标语种；源语种或目标语种必须是中文/英文 | `zh`、`en`、`pt`、`es`、`ja`、`id`、`de`、`fr` | 目标语种为 `zh` 或 `en` 时可使用公版音色 |
| S2S 自动识别免切换 | 自动识别中文/英文 | `zh`、`en` | 适合中英文自动切换 |
| S2T 语音到文本 | 需指定源语种、目标语种；源语种或目标语种必须是中文/英文；方言仅支持作为源语种 | 外语 20 种，方言 2 种 | 文本输出 |

S2S 公版音色：

- `zh_female_vv_uranus_bigtts`
- `zh_male_jingqiangkanye_emo_mars_bigtts`

## 协议

AST 使用 WebSocket 承载 protobuf 数据。当前 SDK 内部维护了满足同传接口所需字段的 protobuf 编解码。

客户端事件：

| Event | 值 | 说明 |
| --- | ---: | --- |
| `StartSession` | `100` | 建联请求 |
| `UpdateConfig` | `201` | 更新参数 |
| `TaskRequest` | `200` | 发送音频数据 |
| `FinishSession` | `102` | 结束 session |

服务端事件：

| Event | 值 | 说明 |
| --- | ---: | --- |
| `SessionStarted` | `150` | 建联成功 |
| `SourceSubtitleStart` | `650` | 原文开始 |
| `SourceSubtitleResponse` | `651` | 原文数据 |
| `SourceSubtitleEnd` | `652` | 原文结束 |
| `TranslationSubtitleStart` | `653` | 译文开始 |
| `TranslationSubtitleResponse` | `654` | 译文数据 |
| `TranslationSubtitleEnd` | `655` | 译文结束 |
| `TTSSentenceStart` | `350` | TTS 开始 |
| `TTSResponse` | `352` | TTS 音频数据 |
| `TTSSentenceEnd` | `351` | TTS 结束 |
| `UsageResponse` | `154` | 计量计费 |
| `SessionFinished` | `152` | 会话正常结束 |
| `SessionFailed` | `153` | 会话失败 |
| `AudioMuted` | `250` | 静音事件 |

## SDK 快速开始

```go
ctx := context.Background()

client := doubaospeech.NewClient(
	doubaospeech.WithAppID(appID, accessKey, ""),
	doubaospeech.WithResourceID(doubaospeech.ResourceASTTranslate),
	doubaospeech.WithUserID("ast-user"),
)

cfg := doubaospeech.DefaultASTTranslateConfig()
cfg.Mode = doubaospeech.ASTTranslateModeS2T
cfg.SourceLanguage = "zh"
cfg.TargetLanguage = "en"

session, err := client.ASTTranslate.OpenSession(ctx, &cfg)
if err != nil {
	return err
}
defer session.Close()

if err := session.SendAudio(ctx, pcm16kMonoChunk); err != nil {
	return err
}
if err := session.Finish(ctx); err != nil {
	return err
}

for {
	evt, err := session.RecvEvent(ctx)
	if err != nil {
		return err
	}
	if evt == nil || evt.IsFinal {
		break
	}
	if evt.Type == doubaospeech.ASTEventTranslationSubtitleResponse {
		fmt.Println(evt.Text)
	}
}
```

SDK 覆盖范围：

- `ASTTranslate.OpenSession(ctx, cfg)`：建立 WebSocket、发送 `StartSession`、等待 `SessionStarted`。
- `ASTTranslateSession.SendAudio(ctx, audio)`：发送 `TaskRequest`。
- `ASTTranslateSession.UpdateConfig(ctx, update)`：更新语料、热词、术语等配置。
- `ASTTranslateSession.Finish(ctx)`：发送 `FinishSession`。
- `ASTTranslateSession.RecvEvent(ctx)` / `Recv()`：接收并解析服务端事件。
- `ASTTranslateSession.Close()`：尽力结束并关闭连接。

## StartSession

WebSocket 升级后，客户端发送的第一个业务请求是 `StartSession`。

必填字段：

- `request_meta.session_id`：会话 ID，建议 UUID。
- `event`：固定 `100`。
- `request`：请求配置。
- `source_audio`：源音频配置。
- `target_audio`：S2S 必填，S2T 可不填。

常用字段：

| 字段 | 必选 | 说明 |
| --- | --- | --- |
| `request.mode` | 否 | `s2t` 或 `s2s` |
| `request.speaker_id` | 否 | 输出音色；不传或传错则默认复刻输入音色 |
| `request.is_custom_speaker` | 否 | 外接音色是否为复刻音色 |
| `request.tts_resource_id` | 条件必填 | 走精品/复刻音色链路时必填，可选 `seed-tts-1.0`、`seed-tts-2.0`、`seed-icl-1.0`、`seed-icl-2.0` |
| `request.speech_rate` | 否 | 语速，范围 `[-50,100]` |
| `request.source_language` | 是 | 源语种 |
| `request.target_language` | 是 | 目标语种 |
| `request.enable_source_language_detect` | 否 | 是否在 `SourceSubtitleEnd` 返回原文语种标签 |
| `request.corpus` | 否 | 热词、替换词、术语词等，合计不超过 1000 个 |

源音频配置：

| 字段 | 必选 | 说明 |
| --- | --- | --- |
| `source_audio.format` | 是 | `wav`，仅支持 wav |
| `source_audio.codec` | 否 | `raw`，仅支持 raw |
| `source_audio.rate` | 是 | 必须 `16000` |
| `source_audio.bits` | 是 | 必须 `16` |
| `source_audio.channel` | 是 | 必须 `1`，单声道 |

目标音频配置：

| 字段 | 必选 | 说明 |
| --- | --- | --- |
| `target_audio.format` | S2S 必填 | `pcm` 或 `ogg_opus` |
| `target_audio.rate` | S2S 必填 | 默认 `24000`，支持 `16000` / `24000` |

注意：

- `pcm` 格式在 16 kHz 下默认 16-bit 整型。
- `pcm` 格式在 24 kHz 下默认 32-bit float。
- `ogg_opus` 输出采样率固定为 48 kHz，`rate` 配置不改变该格式采样率。

## 发送音频 TaskRequest

收到 `SessionStarted` 后再发送参数包和音频包。

`TaskRequest` 字段：

| 字段 | 必选 | 说明 |
| --- | --- | --- |
| `event` | 是 | 固定 `200` |
| `source_audio.data` | 是 | 音频流二进制数据 |

音频要求：

- 16 kHz
- 16-bit
- 单声道
- wav / pcm
- 建议 80 ms 一包

## UpdateConfig

`UpdateConfig` 用于在 session 中更新热词、替换词、术语等语料配置。

注意：当前不支持在会话中切换语言和 mode。如需切换，请重新建立 session。

## FinishSession

所有音频发送完毕后，发送 `FinishSession`：

```json
{
  "event": 102
}
```

## 服务端响应

常用响应字段：

| 字段 | 说明 |
| --- | --- |
| `response_meta.status_code` | 错误码 |
| `response_meta.message` | 错误信息 |
| `response_meta.billing` | 计量计费信息，仅 `UsageResponse` 返回 |
| `event` | 响应事件 |
| `text` | 原文或译文文本 |
| `data` | 返回的二进制音频数据 |
| `start_time` | 起始时间，毫秒 |
| `end_time` | 结束时间，毫秒 |
| `spk_chg` | 说话人是否切换 |
| `muted_duration_ms` | 静音时间，毫秒 |

事件示例：

- `SessionStarted`：建联成功。
- `SourceSubtitleStart` / `SourceSubtitleResponse` / `SourceSubtitleEnd`：原文开始、原文数据、原文结束。
- `TranslationSubtitleStart` / `TranslationSubtitleResponse` / `TranslationSubtitleEnd`：译文开始、译文数据、译文结束。
- `TTSSentenceStart` / `TTSResponse` / `TTSSentenceEnd`：TTS 开始、音频数据、TTS 结束。
- `UsageResponse`：返回 `output_text_tokens`、`output_audio_tokens`、`input_audio_tokens` 等计费项。
- `AudioMuted`：VAD 检测到静音，首次约静音 2 秒后返回，之后约每静音 1 秒返回一次。

## 错误码

| 错误码 | 含义 |
| --- | --- |
| `20000000` | 成功 |
| `45000001` | 请求参数无效 |
| `45000002` | 空音频 |
| `45000081` | 等包超时 |
| `45000151` | 音频格式不正确 |
| `550xxxxx` | 服务内部处理错误 |
| `55000031` | 服务器繁忙 |
